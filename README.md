# CyberPeek

CyberPeek 是用 Swift 和 AppKit 编写的轻量级 macOS 代码编辑器，适合在 coding agent 改完代码后阅读源码和审阅差异。打开一个文件夹即可浏览、编辑、搜索或审阅 Git 改动。需要 macOS 14 或更高版本。

## 使用

| 操作 | 快捷键 |
| --- | --- |
| 新建窗口 / 关闭窗口 | ⌘N / ⇧⌘W |
| 打开文件夹 | ⇧⌘O |
| 打开文件 | ⌘O |
| 按名称定位文件，支持 `路径:行号` | ⌘P |
| 当前文件查找 / 下一个匹配 | ⌘F / ⌘G |
| 工作区关键词搜索 | ⇧⌘F |
| 资源管理器 / 源代码管理 | ⇧⌘E / ⌃⇧G |
| 切换侧边栏 | ⌘B |
| 放大 / 缩小编辑器字号 | ⌘+（或 ⌘=）/ ⌘− |
| 恢复默认字号（24 pt） | ⌘0 |
| 返回 / 前进 | ⌃− / ⌃⇧− |
| 保存 / 关闭当前标签 | ⌘S / ⌘W |

每个窗口有独立的工作区。打开另一个文件夹时会复用空窗口，或新建窗口。再次打开同一个文件夹，会将已有窗口置前，已最小化的窗口也会恢复。从 Finder 打开文件时，文件会进入包含它的工作区。如果父子文件夹都已打开，会优先进入子文件夹的窗口。

退出后重新打开 CyberPeek，会恢复各工作区的标签顺序、选中的标签和固定或预览状态。源码和图片从磁盘重新读取，Git 差异和历史版本会重新加载。已删除的文件、已经消失的差异和无法读取的版本会自动跳过。退出时有未保存的修改，仍可选择保存、放弃修改或取消退出。

单击文件可预览，双击或编辑可固定标签。点击面包屑末尾的复制按钮，或在文件树中右键文件或目录，即可复制相对于工作区根目录的路径。Git 面板分别显示已暂存、未暂存和未跟踪文件，并可展开最近 12 次提交。点击 diff 中的新增行或上下文行，跳转到对应的工作区、暂存区或提交版本。

整个目录都未跟踪时，Git 面板将它计为一项。逐层展开目录即可查看文件及其差异，列表遵守仓库的 Git 忽略规则。

打开 PNG、JPEG、GIF、WebP、AVIF、ICO 或 BMP 文件可直接预览图片。动图 GIF、APNG 和 WebP 会在预览中播放。SVG 默认显示可编辑的源代码，点击面包屑右端、变更箭头左侧的眼睛按钮可预览当前内容，再点代码按钮即可返回编辑。

资源管理器会在文件名右侧显示 Git 状态，例如 `M`（修改）、`D`（删除）、`U`（未跟踪）。有两项状态时按暂存区、工作区的顺序显示。目录旁的圆点表示内部有改动，点击已删除的文件可查看删除差异。

右键文件或目录，选择「在 Finder 中显示」，即可在 Finder 的上级目录中选中该项。右键文件并选择「移到废纸篓」即可删除，之后可以从 macOS 废纸篓恢复。如果文件有未保存的编辑，会先询问是否保存。

打开工作区文件时，编辑器会把当前文字与最近一次提交比较。行号最左侧的绿色竖线和淡绿底纹表示新增，蓝色竖线和淡蓝底纹表示修改。删除位置用行间的红色小三角表示，悬停可查看删除行数。暂存和未保存的编辑都会反映在这些标记中。

点击面包屑最右侧的 ↑ 或 ↓，可在当前文件的各处变更之间循环跳转。变更段和删除标记会尽量居中，靠近文件首尾时最多滚动到页顶或页底。超过一屏的变更段从首行开始显示。

在「查看 → 编辑器字号」中可以选择 9–32 pt。字号对所有编辑器标签页生效，行号随正文缩放，重启后会记住选择。

快速打开、全文搜索和文件监听都以打开的文件夹为范围。快速打开和全文搜索默认跳过任意层级的 `node_modules` 目录。首次按 ⌘P 时会在后台建立文件名索引，索引期间可以继续输入。打开 Git 仓库的子目录时，源代码管理面板只列出涉及该子目录的改动和提交。

如果打开的文件夹不属于 Git 仓库，CyberPeek 会在其中查找各个仓库和 Git 工作树，并在源代码管理面板按仓库列出变更和提交。左下角显示当前标签页所属仓库的分支。打开仓库外的文件时，分支栏会隐藏。

打开的源码会跟踪磁盘变化。当存在本地编辑时，查看器保留缓冲区并提供版本比较。支持 UTF-8 和带 BOM 的 UTF-16，保存时保留原编码以及普通 LF / CRLF 换行。

Tree-sitter 提供 Markdown、Swift、JavaScript / JSX、TypeScript / TSX、Python、C、JSON 和 Bash 高亮。打开 `.md` 或 `.markdown` 文件时，编辑器会突出显示标题、强调、链接、列表、任务框、表格和行内代码。围栏代码块可以按标注的编程语言高亮。其他文本以纯文本显示。单个文本文件上限为 32 MiB，超过 150 万个 UTF-16 单元时使用纯文本。项目搜索遵循 ripgrep 忽略规则，最多显示 1200 个匹配。

## 构建

Release 默认构建 Apple Silicon（arm64）版本。可以在 Xcode 中打开 `CyberPeek.xcodeproj` 运行 CyberPeek，也可以在终端执行：

```sh
xcodebuild -project CyberPeek.xcodeproj -scheme CyberPeek -configuration Release \
  -derivedDataPath .build build
open .build/Build/Products/Release/CyberPeek.app
```

首次构建从 npm 和上游 GitHub 发布页下载锁定版本并校验摘要，依赖缓存位于 `.vendor`。构建需要完整的 Xcode 和 Python 3。应用自带 ripgrep 和语法解析器，运行时 Git 功能使用 `/usr/bin/git`。

安装后，可以从终端打开当前文件夹：

```sh
open -a CyberPeek "$PWD"
```
